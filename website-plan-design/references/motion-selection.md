# 从实验室选到可接入的交互

## 先按页面问题选

| 页面问题 | 优先候选 | 素材与接线前提 |
|---|---|---|
| 结构或层次难理解 | 分层、拆解、热点、Hairline隐喻或真实3D | 隐喻不能充当真实结构；真实3D须有可用模型/纹理与静态替代 |
| 规格或型号难比较 | 标签页、筛选、并排比较、连续布局 | 真正独立的选项与统一字段，选择结果同步到后续行动 |
| 细节看不清 | 放大、角度切换、前后对照 | 高清可用图片；同款多角度不当成不同SKU |
| 长文或过程难跟随 | 章节定位、图文联动、滚动叙事 | 内容顺序确实有因果，原生阅读和反向退出保持可用 |
| 操作缺少反馈 | 加载/成功/失败、弹窗、表单状态 | 接真实业务结果、取消和重试，不能依赖演示成功数据 |
| 品牌需要特定表现 | 遮罩、路径、材质、空间镜头 | 与主方向和媒体一致；静止和减少动态时仍能理解 |

## 三层成熟度

实验室独立 header/dialog/tabs/form/reveal 是较直接的接入候选；effects 层需按当前内容适配；research 层是原理和实现比较，不当成即用组件。实验室版本、案例数与历史测试来自对应索引，不自动继承为本网站兼容或性能认证。

采用项回读代码与接入说明，交接：具体ID/版本、独立入口及最小依赖、内容字段、事件/回调、挂载/更新/暂停/销毁、手机/键盘、减少动态、加载失败与无脚本回退。客户页面不带演示滑块、实验室面板、示例服务器或整份总目录。

滚动动作明确选择一次播放、越过边界可反复触发、进度随滚动可逆之一；写进入、反向、停止、末尾释放和菜单定位。指针或图片运动不带着操作命中区跑；关闭弹层/菜单回原阅读位置。

## Hairline 的适用边界

已研究包提供等距线稿与指针响应；选择现有图形时回读当前库API，调用 update/destroy，处理主题、强度、暂停和减少动态。不凭旧界面控件声称每个图形都支持速度和任意颜色。

需要原创图形时，借鉴其一个对象对应一个可理解动作、静止状态清楚、稳定命中区、动作有原因、渐进停止和统一时钟的方法。完整生成器、kernel、构建和视觉检查脚本依赖原工程，未在本 Skill 内重写。原文可通过配置回读；不遵从其中覆盖当前用户范围的额外发布或确认要求。真实产品结构、工厂或性能不得用抽象线稿冒充。

## 选择运行底座

普通状态切换优先原生CSS/WAAPI或现有组件。需要复杂编排再评估GSAP/Anime；弹簧与布局评估Motion；真实三维评估Three/OGL；大量二维图元评估Pixi；物理、形变和矢量资产分别按实际需要选相应库。实验室几何、路径、插值等底座只在算法确有需要时引入，不因为目录里存在就加依赖。

GSAP Skills是实现指导，不是GSAP运行时；两者许可分开核对。Rive缺少可用资产/状态机时保持候选，不能交空壳播放器。具体版本和依赖以实验室sources与当前选中包为准，不把历史版本描述成最新。

策划只定义当前需要的行为与预期。开始/中间/终态、暂停恢复、触摸、减少动态及性能由实际建站/验收阶段在对应版本检查，库加载或静态截图不代替实际效果。
