# 将历史体验问题前移到设计阶段

来源是用户提供的既有网站体验复盘，经通用化整理。它说明过去出现过哪些风险，不是当前网站通过的证据。原站配色、字体、摄影年龄感、轮播速度、列数与吸附段数不成为通用默认。

## 保留与改变

已有网站先列“用户已确认保留、此次需要改善、尚未确认”。用户喜欢的摄影、轮播、轻摆、菜单、叙事或页脚不能因局部优化被统一替换。新产品仍从自身任务重新决定版式。局部优化只定义受影响模块与必要关联，不因完整检查表而重新设计全站；源码推测不能冒充截图问题已解决。

## 交互与降级须在方案中定义

| 风险 | 设计决定与交接 | 后续可观察预期 |
|---|---|---|
| 导航文字同时承担跳转和展开 | 一级页面链接与展开控件职责明确；定义展开/返回/关闭、Esc、焦点、滚动锁和原阅读位置 | 鼠标、触摸、键盘能完成同一任务；关闭不丢位置或遗留遮罩 |
| 点击目标随图片运动 | 动画发生在内部媒体层，链接与按钮命中区稳定 | 播放、中断、切换时仍能自然点击，不用强制点击绕过 |
| 吸附进入后无法退出、定位被页眉遮挡 | 写明段落范围、占位、正反向、章节定位、收缩页眉偏移、结束释放及菜单返回，保留原生竖向滚动 | 从进入到退出形成完整路径，不只看停靠截图 |
| 减少动态时叠放或误选阶段 | 单独设计静态阅读顺序与降级布局，而非仅将时长归零；阶段式内容通常转连续阅读，再按本产品决定列数 | 内容完整、顺序清晰，当前项不依赖多个阶段的相同顶部坐标 |
| 普通网址与参数入口效果不同 | 明确默认、跟随系统、站内选择、保存/撤回、返回页面的优先关系，不擅自覆盖既有偏好 | 普通入口、显式减少动态与系统偏好分别有可解释行为 |
| 手机操作区小、横屏面板截断 | 页眉搜索、菜单、语言和主要行动有可触达命中区；考虑安全区、软键盘、横向和平板重排 | 相应尺寸可读可点可滚动，不能仅缩小桌面版 |

触摸目标可从约44 CSS px作为设计起点，再按布局和任务判断；不是所有组件的唯一尺寸或合规证明。

## 图片的内容结构与生命周期

1. **产品与角度分开。** 主要浏览序列通常帮助比较不同SKU，同款正背/细节归属该商品；颜色确为购买维度时可明确作为变体比较。间隔与拖动按当前需求决定，不继承某站两秒设置。
2. **先分配用途再制作。** 素材清单标出模块、产品/角度、构图焦点、桌面/手机裁切和允许复用范围。避免相邻叙事无意重复同图；Logo、必要商品对照与共用说明可合理复用，不能从同页扫描推导全站禁复用。
3. **摄影服从当前品牌。** 年龄感、明暗、背景、材质和结构要匹配产品，不能把“年轻明亮”固化成所有行业默认。生成素材检查人脸/手部、面料或材质、形体和产品结构，仍标明概念图，不冒充实拍。
4. **先设计未就绪和失败状态。** 列表图、主图、放大图分工，稳定占位并保持清晰比例。首图优先，非当前角度、菜单图和隐藏大图按意图或接近视口加载；下一张未准备好时保留当前图，解码后切换，失败不显示空白轮播。
5. **裁切边界明确。** 圆角、遮罩和背景由哪层外框控制，内图轻摆/缩放/换图时怎样保持边缘。已有工程交接实际DOM、旧样式优先级与外框核对点，不猜选择器再叠全局样式。

图片策略是设计输入，不只留给最后性能优化。少请求若干隐藏图只证明对应条件下请求减少，不能承诺所有网络更快或首屏指标达标。

## 阅读层次与动效角色

优先用字号、字重、行宽、行高、内容分组和均衡换行建立层次。中文检查有意义词组、英文与数字检查行长和单位；样板使用真实长标题、翻译扩展和正文，不能靠删短文字掩盖布局问题。用户确认的特殊标题可以保留，不给全站标题套同一手绘线或装饰。

时长按角色决定：阅读入场不拖住获取信息，菜单反馈跟手，产品叙事保留必要停留。原复盘中的720ms、320ms等是该站当时选择，不是全行业常数；也不因“克制”直接删除用户喜欢的效果。运动不能抢走操作。

实验室接入只带客户能理解的内容与行为，调试滑块、原始矩阵、无意义箭头和控制台不进入客户界面，除非本来就是产品功能。

## 交给建站和验收

实际采用项写成“当前模块→设计决定→内容/素材与接口→普通/失败/减少动态状态→相关设备→可观察预期”，区分继承、改写和新增来源。建站核对真实DOM、组件状态和数据；验收检查当前版本与普通入口。

要求三端时明确电脑、平板、手机及相关引擎，模拟不称实体手机或微信实测。旧测试版本、固定图数、假设存在的状态字段不作为设计事实；后续测试读取当前数据，区分测试错误和产品错误。证据失效/工具失败保留未验证，截图采集与目视、源码与实际动画分开。后补研究只支持当前修订，不倒写旧版来源。

按已有有效基线定向复验，不把局部任务变成整站重复检查。本经验文档不代表自动验收或新站效果保证。
