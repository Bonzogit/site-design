# 全部资料的迁移

## 两种交付物

- **轻量Skill仓库**：策划方法、能力卡、读取/迁移脚本和来源说明，可独立研究与输出方案。
- **完整离线迁移包**：Skill加已选资料的完整目录，包括规范原文及其发布依赖、实验室源码/素材/第三方通知、研究Skill原文和配套文件。它是用户已有资料的私有迁移副本，不因本Skill采用MIT而重新授权第三方内容。

迁移包使用resources.json中的相对根目录。导出时不携带旧机器的配置路径；包内保留源码相对引用、原许可证和必要文件。已配置文档白名单决定搜索范围，但完整目录保留配套代码。Git元数据、node_modules/虚拟环境/缓存、凭据和环境密钥不导出；符号链接拒绝并要求明确处理。

## 新电脑怎么用

需要Python 3.10或更高版本。把完整ZIP复制到新电脑，解压到准备长期保留的目录，在该目录运行：

```text
python website-plan-design/scripts/portable_resources.py verify .
python website-plan-design/scripts/portable_resources.py install .
```

verify逐文件检查摘要、缺失/额外文件、资料根目录和索引可读性。install复制Skill到当前CODEX_HOME/skills或用户主目录.codex/skills，并把本机配置指向当前解压位置；不会使用导出电脑的绝对路径。**安装后保留完整资源文件夹**，不能只留下Skill文件夹再删除资料。

已有同名Skill或资源配置时安装器明确停止，保留现状，由执行者比较并合并，不自动覆盖其他资源。需要自定义宿主位置时用 `install . --home <当前宿主配置目录>`。移动已安装资料目录后，需重新核对本机配置，不宣称自动追踪文件夹移动。

也可用脚本安全解压：`python <本Skill>/scripts/portable_resources.py unpack <完整ZIP> <不存在的新目录>`。解压拒绝越界、重复文件、符号链接和超限归档。普通系统解压后仍应运行verify。

## 从当前环境重新导出

```text
python scripts/portable_resources.py export --config <本机私有资源配置> --output <新的完整ZIP路径>
```

导出只处理显式配置的资料根目录，不遍历整台电脑。先检查根目录确为可迁移资源，不包含客户数据和口令；保留输出ZIP的SHA-256。旧ZIP不会覆盖。目录缺失、符号链接或实际索引不可用时说明缺口，不生成声称完整的成功报告。

## 资料迁移与工具运行

规范、实验室及研究源码可离线读取；相关静态文件和原始脚本已保留。但Node/Python依赖、浏览器、GPU、剪映应用、Refero订阅、ImageGen等宿主工具、翻译/邮件/部署服务和密钥不是资料文件。换电脑需要对应环境与授权，运行检查另记，资料校验通过不能替代。

之前缺失的四项辅助来源按旧研究固定提交重新获取，记录下载URL、提交、归档摘要与许可文件后纳入资源配置；只恢复源码，不宣称Impeccable平台CLI等二进制已安装。下载失败时在来源状态中保留缺失，不偷换为最新版本。
