# 交接前自查

这是策划方案的检查，不是网站成品验收。只检查当前承诺的设计范围；页面尚未实现时不能填画面或功能通过。

| 检查 | 不足的表现 | 交接前补什么 |
|---|---|---|
| 任务明确 | 只有行业名和“提高转化” | 主要访客、入口、要判断的事、主要行动与条件 |
| 模块必要 | 只有通用章节标题 | 模块回答的问题、顺序理由、内容草稿；删掉无任务作用的模块 |
| 内容可用 | 所有文字都是“待填”，或无来源的宣传数字 | 可修改的主要文案与真实内容，事实和假设分开，缺项定位到模块 |
| 设计可实现 | 只有“高端、简洁”，无布局和尺寸选择 | 图文关系、字体层次、色彩角色、间距/宽度、裁切与组件参数 |
| 素材可获得 | 主方向依赖不存在的实拍或动画 | 可用资产或明确制作要求；说明未取得资产及可成立的回退 |
| 操作闭合 | 只写“加筛选/表单/动效” | 输入、状态、结果、失败恢复、返回与手机/减少动态行为 |
| 接线有依据 | 演示控件存在，但选项保存位置不明 | 内容字段、编辑位置、接口、持久化与前端状态边界，未知处标记待建站确认 |
| 验收可执行 | 只写“体验良好、三端适配” | 可观察的预期、相关页面/状态/设备及需要实际验证的事项 |
| 来源可核对 | 只有网站名或目录搜索结果 | 页面/文件、观察方式、采用点、版本或时间、依赖与许可状态 |

结论分为：足以进入样板；部分范围可开始、其他项待补；关键依赖阻断。说明是哪一项及影响，不输出未经证实的总分。普通缺图、次要文案或未定细节不自动阻断整站，应缩小到可实现范围；缺失真实价格、库存或交易能力时不能假造商业链路。

交给建站时保留需要实测的预期与未决项，交给验收时提供同一方案及后续修订记录。记录检查器通过只证明其覆盖的字段或文件关系，不是设计质量认证。
